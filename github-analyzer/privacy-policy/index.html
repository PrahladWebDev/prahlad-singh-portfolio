GITHUB ANALYZER

Privacy Policy

Last updated: 30 September 2026

GitHub Analyzer (web, Android and Windows) analyzes a public GitHub profile and shows scores, charts and an AI-written summary. There are no accounts and no sign-in. This policy explains what the app handles and why.

Information we handle

CategoryWhat it includes
GitHub usernameThe username you type in to analyze (or compare). It is sent to our server to fetch that profile's data.
Public GitHub dataPublic profile details, repositories, languages and commit activity for that username, retrieved from the GitHub API.
On your deviceYour chosen theme and your recent searches, saved in local storage on your device only.

We do not ask for, collect or store your name, email, password, or any private GitHub data. The app does not request access to your GitHub account.

How we use it

  • To retrieve the public GitHub data for the username you enter and compute scores, badges and charts.
  • To generate the AI summary of that public data.
  • To protect the service from abuse (rate limiting).

We do not sell your information, and we do not use it for advertising or tracking.

Third-party services

  • GitHub API — the source of the public profile and repository data.
  • Google Gemini API — receives a summary of the public GitHub data (such as profile details, language stats, repository names and activity) to write the AI summary. No personal details beyond what is already public on GitHub are sent.
  • Our own backend server, which relays requests to the services above.

Data storage and security

We do not keep a database of analyzed profiles or user data. Like most web servers, ours may temporarily record technical information such as IP address and request time in standard logs, used for security and rate limiting. Data travels over encrypted (HTTPS) connections.

Your choices

  • You can clear your recent searches inside the app at any time, or clear the app's local data from your browser or device settings.
  • Since there are no accounts, there is no account to delete. If you want a specific request removed from our server logs, contact us below.

Children's privacy

GitHub Analyzer is not directed at children under 13 and does not knowingly collect personal information from them.

Changes to this policy

We may update this policy as the app changes. Changes will be reflected here with an updated "Last updated" date.
